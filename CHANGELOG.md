# Changelog - Проект: Веб-сервис для создания карточных игр


## [0.16.2] - 2025-04-14 

#### **1. Добавление библиотеки для работы с изображениями**  
- **Изменения**:  
  - Установлена библиотека `Pillow` для обработки изображений.  
- **Затронутые файлы**:  
  - `requirements.txt` (добавлена строка `Pillow`).  
---
#### **2. Создание нового приложения `export`**  
- **Изменения**:  
  - Добавлено приложение `export` для генерации PDF-файлов.  
  - Настройки проекта обновлены для подключения приложения.  
- **Затронутые файлы**:  
  - `config/settings.py` (добавлено `'export'` в `INSTALLED_APPS`).  
  - Создана структура приложения:  
    ```
    export/
      ├── __init__.py
      ├── admin.py
      ├── apps.py
      └── models.py
    ```

#### **3. Реализация связанных моделей**  
- **Изменения**:  
  - Созданы модели `CardTemplate` (шаблон карточки) и `CardInstance` (экземпляр карточки).  
  - Добавлена связь `ForeignKey` между моделями.  
- **Затронутые файлы**:  
  - `cards/models.py` (реализация моделей).  
  - Миграции:  
    - `cards/migrations/0001_initial.py`  
    - `cards/migrations/0003_cardinstance.py`  
---
#### **4. Настройка статических и медиафайлов**  
- **Изменения**:  
  - Добавлены настройки для работы со статикой и медиафайлами.  
  - Настроены пути для загрузки изображений.  
- **Затронутые файлы**:  
  - `config/settings.py` (добавлены `STATIC_URL`, `MEDIA_URL`, `MEDIA_ROOT`).  
  - `config/urls.py` (добавлена обработка медиафайлов).

#### **5. Настройка маршрутов приложений**
